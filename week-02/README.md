# Week 2: number_utils module (WB-02)

A reusable module of number utilities and a menu program that uses it.

## Checklist
- [ ] `number_utils.py` with `is_prime`, `gcd`, `lcm`, `is_palindrome`, `is_armstrong`, `digit_sum`, `reverse_number`, `fibonacci`
- [ ] Every function has a docstring and handles 0 and negative input sensibly
- [ ] At least 2 `assert` test calls per function under `if __name__ == "__main__":`
- [ ] `menu.py` imports the module, loops until exit, rejects invalid choices without crashing
- [ ] `trace.jpg`: a photo of one function hand-traced on paper
- [ ] Stretch: `count_primes(n)` with the Sieve of Eratosthenes and its complexity in a comment

## How to run

```bash
python number_utils.py   # runs the tests
python menu.py
```
