# Week 17: EDA, insights report and dashboard (WB-17)

Same dataset as Week 16.

## Checklist
- [ ] `eda.ipynb` follows questions → univariate → bivariate → multivariate, with descriptive statistics, a correlation heatmap and an outlier check
- [ ] At least 8 charts, each with a title, axis labels and a one-line takeaway
- [ ] `insights.pdf`: one page, 3–5 actionable insights, each backed by a chart or number
- [ ] `dashboard.py`: Streamlit app with at least 2 filters and 3 charts
- [ ] Stretch: dashboard deployed on Streamlit Community Cloud (put the URL in your submission)

## How to run

```bash
pip install -r requirements.txt
streamlit run dashboard.py
```
